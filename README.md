# Milwaukee Black Friday 2026 Deals

A one-time snapshot of Milwaukee Tool sales, checked Wednesday, Nov 25, 2026 (America/Chicago). Built so friends can open the list on a phone with no login.

**Live site:** https://sbezner.github.io/milwaukee-black-friday-2026/

The page lists all 142 deals in a single scrolling results list, like a store search page. Search by tool name, model, category, or store. Filter by category or store on the left (on a phone, open Filters). Prices change, so confirm the live price on the store page before you buy.

This is a static site: `index.html` with inline CSS and JavaScript, plus a `.nojekyll` file so GitHub Pages serves it from the `main` branch root.
