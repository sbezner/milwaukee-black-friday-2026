# Milwaukee Black Friday 2026 Deals

A snapshot of Milwaukee Tool sales, checked Thursday, Nov 26, 2026 (America/Chicago). Built so friends can open the list on a phone with no login.

**Live site:** https://sbezner.github.io/milwaukee-black-friday-2026/

The page lists 475 deals in a single scrolling results list, like a store search page. Each row has a product photo, the sale price, the regular price when we had it, and a button to the store product page. Search by tool name, model, category, or store. Filter by category or store on the left (on a phone, open Filters). Prices change, so confirm the live price on the store page before you buy.
