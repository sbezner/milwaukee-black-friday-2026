# Milwaukee Black Friday 2026 Deals

A snapshot of Milwaukee Tool sales, checked Friday, Nov 27, 2026 (America/Chicago). Built so friends can open the list on a phone with no login.

**Live site:** https://sbezner.github.io/milwaukee-black-friday-2026/

The page lists 499 deals in a single scrolling results list, like a store search page. Each row has a product photo, the sale price, the regular price when we had it, and a button to the store product page. Search by tool name, model, category, or store. Filter by category or store on the left (on a phone, open Filters). Prices change, so confirm the live price on the store page before you buy.

Stores on this snapshot:

- Tool Nut: 213 deals
- Fasteners Inc: 117 deals
- Home Depot: 98 deals
- Ohio Power Tool: 26 deals
- Ace Hardware: 21 deals
- Walmart: 21 deals
- Acme Tools: 2 deals
- Northern Tool: 1 deals

Fasteners Inc rows use their live online Black Friday prices and direct product pages (they ship to the lower 48). Tool Nut rows come from that store’s Milwaukee deals collection, including items still marked down on the product page. Walmart and Ohio Power Tool rows were rechecked on Nov 27 and new Black Friday markdowns were added. Home Depot, Ace Hardware, Acme Tools, and Northern Tool block automated checks, so those rows were left at the Nov 26 prices. I also checked Lowe’s; a row was added only when I had a current sale price and a direct product link.

This is a static site: `index.html` with inline CSS and JavaScript, product thumbnails in `img/`, and a `.nojekyll` file so GitHub Pages serves it from the `main` branch root.
